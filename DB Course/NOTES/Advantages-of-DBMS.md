# Advantages of a DBMS

A Database Management System is software that stores, organises and controls access to data.

| Advantage | Meaning | Example |
|---|---|---|
| Data independence | Storage details are separated from how applications use the data | Changing file organisation does not break the application |
| Efficient data access | Indexes and query optimisation retrieve data quickly | A query finds one record among millions in milliseconds |
| Integrity and security | Constraints keep data correct; permissions restrict access | Only authorised staff can view customer balances |
| Data administration | Central control of large shared data | University records for students, courses and faculty |
| Concurrent access and crash recovery | Many users work at once; logs restore data after failure | Online orders survive a server crash |
| Reduced development time | Storage, querying and security are already built in | Developers write SQL instead of file-handling code |
