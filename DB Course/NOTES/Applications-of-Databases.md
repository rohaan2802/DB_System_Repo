# Applications of Databases

Databases store, manage and retrieve data in almost every industry.

| Area | What is stored | Typical systems |
|---|---|---|
| Banking and finance | Accounts, transactions, loans, fraud checks | Oracle, MySQL, PostgreSQL |
| E-commerce and retail | Inventory, product catalogues, orders, payments | MySQL, MongoDB, DynamoDB |
| Healthcare | Patient records (EHR), appointments, prescriptions | SQL Server, PostgreSQL |
| Social media | Profiles, posts, messages, friend graphs | MySQL, Cassandra, Neo4j |
| Education | Student records, courses, results, attendance | PostgreSQL, SQL Server |
| Government | Census, tax, vehicle registration, national ID | Oracle, PostgreSQL |
| Transport and logistics | Reservations, schedules, vehicle tracking, supply chain | PostgreSQL, MongoDB, DynamoDB |
| Streaming services | Watch history, recommendations, content metadata | Cassandra, MySQL, Redis |
| Manufacturing | Raw material stock, production schedules, machine data | Oracle, SQL Server |
| Security and fraud detection | Access logs, suspicious transactions | PostgreSQL, Elasticsearch, Neo4j |

**Key point:** the choice of database depends on the data shape (tables, documents, graphs, time series) and the workload (transactions, analytics, real-time reads).
