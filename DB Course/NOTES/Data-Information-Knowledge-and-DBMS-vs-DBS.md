# Data, Information, Knowledge and DBMS vs Database System

## Data → Information → Knowledge
1. **Data:** raw, unprocessed facts, e.g. a table of employee IDs, names, ages and salaries.
2. **Information:** data processed to have meaning, e.g. a report showing which employees earn more than average.
3. **Knowledge:** insight used to make decisions, e.g. deciding to raise salaries in a department where staff are leaving.

In a database, data is stored in tables, information is produced through queries and reports, and knowledge comes from analysing patterns in that information.

## DBMS vs Database System
| Feature | DBMS | Database System (DBS) |
|---|---|---|
| Definition | Software for creating, managing and querying databases | The complete environment: DBMS + database + hardware + users + procedures |
| Components | Query processor, storage manager, transaction manager | Hardware, software, data, users, procedures |
| Scope | Storing and retrieving data efficiently | The whole data-management ecosystem of an organisation |
| Examples | MySQL, PostgreSQL, Oracle, SQL Server | A hospital records system or a bank's core system built on a DBMS |

The DBMS is one part of a database system.
