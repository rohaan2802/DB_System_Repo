# Metadata

Metadata is **data about data**: information that describes other data so it can be organised, found and managed.

| Type | Purpose | Example |
|---|---|---|
| Descriptive | Identification and discovery | Title, author, keywords, creation date |
| Structural | How parts relate | Table of contents, pages, file relationships |
| Administrative | Management, technical and rights information | File format, size, permissions, copyright |
| Provenance | Origin and history | Source, modifications |
| Statistical / database | Structure and meaning of stored data | Schema, data types, indexes |

Examples: file name and size in a file system; table names, column types and constraints in a DBMS catalog (`INFORMATION_SCHEMA`); camera model and GPS in a photo.

Uses: faster retrieval, organisation, security and compliance, interoperability.
