# Types of Databases

| Type | Structure | Examples | Typical use |
|---|---|---|---|
| Relational (RDBMS) | Tables with rows and columns, SQL | MySQL, PostgreSQL, Oracle, SQL Server | Banking, ERP, e-commerce |
| NoSQL – document | JSON/BSON documents | MongoDB, CouchDB | Content, catalogues |
| NoSQL – key-value | Key → value pairs | Redis, DynamoDB | Caching, sessions |
| NoSQL – wide column | Column families | Cassandra, HBase | Big data, time-ordered writes |
| NoSQL – graph | Nodes and edges | Neo4j | Social networks, recommendations |
| Hierarchical | Tree (parent–child) | IBM IMS | Legacy banking, telecom |
| Network | Graph of records with many parents | IDS | Complex legacy relationships |
| Object-oriented | Objects as in OOP | ObjectDB, db4o | CAD, multimedia |
| Time-series | Timestamped values | InfluxDB, TimescaleDB | IoT, monitoring, markets |
| Distributed | Data spread across servers | Google Spanner, Cassandra | Large-scale systems |
| Cloud | Managed service | Amazon RDS, Firebase, Snowflake | Scalable hosted apps |
| In-memory | Data held in RAM | Redis, Memcached | Caching, real-time analytics |
| Ledger / blockchain | Append-only, tamper-evident | Hyperledger | Secure transaction records |
| Vector | Embedding vectors with similarity search | FAISS, Milvus, Pinecone | Semantic and image search |
