## Course Overview

Database Systems (CS-2005) and its lab (CL-2005) at FAST-NUCES Islamabad. The repository has the thirteen lecture sets, three textbooks, assignments, quizzes, my study notes and two semesters of labs: Spring 2025 (MS Access, SQL Server, T-SQL, C# WinForms, MongoDB) and Spring 2026 (MS Access, SQL Server, HTML/JavaScript, PHP with MySQL, T-SQL and transactions).

## Topics Covered

| Unit | Topics |
|---|---|
| **Unit 1 – Database concepts** | Data and information, DBMS vs file systems, data models, schemas and the three-schema architecture. |
| **Unit 2 – Conceptual design** | ER and EER modelling, weak entities, specialization, union types and mapping to relations. |
| **Unit 3 – SQL** | DDL, DML, constraints, joins, subqueries, grouping, views, T-SQL, stored procedures and triggers. |
| **Unit 4 – Theory & internals** | Relational algebra, functional dependencies, normalization, query optimization and transactions. |

## Running the Code

```bash
git clone https://github.com/rohaan2802/DB_System_Repo.git
cd DB_System_Repo
```

- **SQL Server labs:** open the `.sql` files in SQL Server Management Studio. Create the Northwind sample database first with `DB Lab_Spring 25/NorthWind DataBase/NorthWind DataBase.sql`.
- **C# WinForms labs (Spring 2025, Labs 11–12):** open the `.sln` file in Visual Studio, restore NuGet packages, and change `Data Source` in the connection string to your own SQL Server instance.
- **PHP labs (Spring 2026, Labs 8–12):** copy the lab folder into `xampp/htdocs`, start Apache and MySQL in XAMPP, import the lab `.sql` file in phpMyAdmin and open the page in a browser.
- **MongoDB lab (Spring 2025, Lab 14):** import the JSON files with `mongoimport` and run the queries from `i222327_Lab_14_DB.txt` in `mongosh`.
- **MS Access labs:** open the `.accdb` files in Microsoft Access.
