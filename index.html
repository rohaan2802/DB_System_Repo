Overview

Database Systems (CS-2005) and its lab (CL-2005) at FAST-NUCES Islamabad. The repository has the thirteen lecture sets, three textbooks, assignments, quizzes, my study notes and two semesters of labs: Spring 2025 (MS Access, SQL Server, T-SQL, C# WinForms, MongoDB) and Spring 2026 (MS Access, SQL Server, HTML/JavaScript, PHP with MySQL, T-SQL and transactions).

Unit 1

Database concepts

Data and information, DBMS vs file systems, data models, schemas and the three-schema architecture.

Unit 2

Conceptual design

ER and EER modelling, weak entities, specialization, union types and mapping to relations.

Unit 3

SQL

DDL, DML, constraints, joins, subqueries, grouping, views, T-SQL, stored procedures and triggers.

Unit 4

Theory & internals

Relational algebra, functional dependencies, normalization, query optimization and transactions.

Get the Files

Clone everything with Git, then load the SQL scripts into SQL Server.

Clone the repository

Command
git clone https://github.com/rohaan2802/DB_System_Repo.git

Create the Northwind sample database

Command
sqlcmd -S localhost\SQLEXPRESS -E -i "DB Lab_Spring 25/NorthWind DataBase/NorthWind DataBase.sql"

The .sql files run in SQL Server Management Studio. The C# labs open in Visual Studio (restore NuGet packages first), the PHP labs run under XAMPP with MySQL, and the Lab 14 queries run in mongosh. Change the server name in the connection strings to your own.
